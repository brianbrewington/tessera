# Durable map state — session log, 2026-08-05/06

What we built, what we found, and (mostly) what turned out to be wrong. Branch: `viewer/durable-state`.

The work started from three questions — *can we drop a file onto a mindmap, does it persist, and where does it
break at scale* — and ended with slices 1 and 2 shipped, an attention-budget mechanism, and a longer list of
corrected mistakes than of features.

---

## 1. What shipped

**Slice 1 — durable layout.** Positions persist in the `layout` table and the viewer reads them instead of
re-settling on every load. The force layout moved from browser JS into `src/layout/settle.ts` as a verbatim
port; the CLI (`view`, `ingest`) is the writer; `exportViewer` carries positions into the `file://` bundle;
the viewer takes an all-or-nothing branch (complete stored layout → never settle; anything missing → ignore
stored layout entirely and settle from seeds).

New nodes are placed by an **anchored incremental settle**: components of newcomers are seeded against the
frozen existing map — graph anchor, then semantic anchor via stored embeddings, then open space — and
relaxed while every pre-existing node stays byte-identical.

**Slice 2 — scenes that survive.** Scenes were camera coordinates in browser localStorage, which worked only
by accident (deterministic seed + fixed node set). They are now **anchored to node ids** in a `scenes` table,
so a scene means "show me these things" and survives any re-settle. Because a `file://` page cannot write
SQLite, the migration is a two-artifact bridge: an **⤓ export** control in the viewer downloads
`scenes.json`, and `tessera scenes import` reads it in. Brian's six real scenes crossed successfully.

**Edge prominence (the attention budget).** `edge_prominence` stores one row per (edge, measure);
`tessera view` computes PageRank-product and edge betweenness; the bundle carries both; the viewer has a
measure selector and a "top N%" slider.

172 tests, 1 deliberately skipped. Every behaviour above was mutation-tested — the fix was broken on purpose
and the suite had to notice.

## 2. Findings worth keeping

### Coincident nodes are welded together forever

`settle()` cannot separate two nodes at identical coordinates: with `dx = dy = 0` the repulsion is
`f·dx/d = 0` for **any** softening value, so the `|| 0.01` guard only prevents a `0/0` NaN. Since §3.3 seeds
every member of a component from one point, the jitter is a **correctness requirement**, not spacing. Found by
mutation-testing the settle port; five review rounds had not.

### The `h` toggle is now a 36-second freeze

Provenance nodes deliberately have no layout until slice 4, so pressing `h` makes the visible set incomplete
and correctly triggers a full fallback settle — **36.6 s** on the 10× graph. Not a regression (every load used
to pay a settle) but now the worst interaction in the viewer, precisely because everything around it got fast.

### Edge weight, as stored, cannot rank anything

`hebbian_weight` is 1 on **94.3%** of real edges in `graphs/big` and `semantic_weight` is `0` on every edge in
every graph. Any "show only strong edges" control would be thresholding a constant.

### The random-walk edge weight is exactly constant — by algebra

For a simple walk on an undirected graph, π(u) = deg(u)/2m, so an edge's traversal rate is
π(u)/deg(u) + π(v)/deg(v) = 1/2m + 1/2m = **1/m for every edge**. Degree cancels. Measured on `graphs/big`:
spread **1.0×**. Candidates, by how much they actually discriminate:

| measure | spread |
|---|---|
| simple random walk | 1.0× |
| PageRank-weighted walk | 2.7× |
| endpoint PageRank product | 96× |
| **edge betweenness** | **13,201×** |

### Betweenness doubles as an entity-resolution diagnostic

The top bridges in `graphs/big`:

```
0.1805  Charnel Cloete    — Mother
0.1768  Dawid Afrika      — Mother
0.1374  Griet Kruiper     — Klipgat Farm
```

Two of the top three run through **"Mother"** — the relational-term over-merge already in `docs/backlog.md`.
A wrongly-merged hub is by construction an enormous artificial bridge, so the same measure that ranks edges
for display also surfaces merges to audit.

### Scale: compute is not the wall

| stage | 1× | 10× | verdict |
|---|---|---|---|
| bootstrap settle | 0.3 s | 31–75 s | fine — one-time CLI cost since slice 1 |
| incremental pass | 0.10 s | 0.42 s | fine — linear in the existing map |
| bundle | 0.8 MB | 6.9–9.3 MB | **the wall** |

Slice 1 converted the only serious compute wall (a per-load quadratic stall) into a one-time cost. What breaks
is transport, and legibility breaks well before that. `graphs/big`'s median neighbourhood Jaccard is **0** —
most edges are in no triangle at all, so the corpus is closer to tree-like than clustered.

## 3. Mistakes, and what they cost

Recorded because the pattern is more useful than any single fix: **every error came from asserting something
checkable without checking it, and every check was cheap.**

| what | how it was caught |
|---|---|
| §2 "ground truth" had **7 factual errors** about the codebase | round-1 review |
| The localStorage migration was **impossible** (no `file://` → SQLite path) | round-1 review |
| Build order contradicted its own writer rule | round-1 review |
| "Reject missing `Origin`" would have **rejected our own EventSource** | round-2 review, then a browser |
| Requiring `Sec-Fetch-Site: same-origin` everywhere would have **blocked the page load** | measured in Chrome |
| `GET /` had no `Host` check — DNS rebinding could read the whole graph | round-2 review |
| Seeding "over the visible set" would have changed **387 of 387** seeds | round-3 review |
| A ladder whose rule (b) made rule (c) **dead code** | round-4 review |
| A cosine floor of 0.60 that sat **below every observed value**, re-deadening (c) | round-5 review, measured |
| Invented `querySimilar`'s signature — twice | rounds 4 and 5 |
| A cohesion benchmark whose scatter arm **never relaxed** | slice-1 review |
| The same confound **reproduced inside the test written to fix it** | own mutation testing |
| `settleIncremental` deletable with **every test still green** | slice-1 review |
| A PRNG that **cycled after 16,403 draws**, producing a fake "hairball" | the picture looked wrong |
| Edge betweenness normalised with the **node** formula (0.5% high) | cross-validation vs networkx |

Two habits did most of the catching:

1. **Mutation testing.** Break the fix on purpose; if the suite stays green the test is decoration. This found
   the welding defect, the unguarded relax, and the blind `ORDER BY` tripwire.
2. **Extract the reference from the shipped artifact.** Tests pull `settle()`, the layout branch, the anchor
   rule and the edge filter out of `viewer/template.html` at test time rather than transcribing them, so a
   shared wrong assumption cannot pass green.

And one that did not work: writing an acceptance criterion by choosing a threshold. Every invented constant —
ring-rate < 10%, cohesion within 2×, cosine floor 0.60 — was wrong when measured. The ones that survived were
derived from data (`SEMANTIC_FLOOR` = 0.75 from a checked-in harness, mean-NN > 50 from a measured 30-vs-72
separation).

## 4. Open, and deliberately not resolved

- **Rule (c) is transient.** Stranded components are parked at `r = 220 + 60j`, but the relax pulls them ~200
  units back toward the origin. If they are meant to *stay* peripheral, that is a physics change (weaker
  gravity, fewer iterations, a soft pin), not a metric retune.
- **No post-relax cohesion metric works.** Three candidates measured; all fail above |C| ≈ 4 because the relax
  washes out the seed. Seed policy is asserted pre-relax instead. `test/layout-pass.test.ts` carries a skipped
  test with the numbers; do not un-skip without a metric shown to discriminate.
- **`mutation_log` coverage is not universal** — `markExtracted` and `recordIngestedSource` write without
  logging. In the backlog as ACCEPTED-RISK.
- **LFR benchmark generation** is written (`scripts/bench/lfr-topology.py`) but needs a larger
  `min_community`; it failed with `ExceededMaxIterations`. networkx now works in a scratch venv.
- **Hub degree is capped by community size** in the synthetic generator (max/median 14×, where a real link
  map is hundreds). Real data — a wiki link map — would test hierarchy far better than anything synthetic.
- **Slice 3 (`tessera serve` + drop target)** and **slice 4 (provenance in layout)** are unstarted. Slice 4
  removes the `h` cliff by construction.
