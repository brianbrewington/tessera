# Data Collection Protocol: Generative Social Simulation

## 1. Metadata Schema (The "Common Header")

Every log entry, whether generated by a Jetson Nano (Episodic) or the Mac Studio (Wisdom), must include a standardized header for cluster-wide alignment.

```json
{
  "timestamp_us": 1678900000000,   // High-precision temporal proximity analysis
  "source_node_id": "nano-01",     // Specific Slurm node (e.g., nano-01, mac-studio)
  "agent_context_id": "Aiden",     // Unique ID of the agent persona
  "partition_type": "dream"        // Slurm partition (dream, wisdom, scribe)
}
```

## 2. Episodic Logs (Captured by Jetson Nanos)

These logs track the **"Short-term Reflex"** and immediate relational interactions.

| Metric Category | Data Points to Capture | Justification |
| :--- | :--- | :--- |
| **Conversation Flow** | Raw text, Turn count, Token speed (t/s) | Measures "Throughput Efficiency" of the distributed nodes. |
| **Affective Resonance** | Valence/Arousal scores per turn, Sentiment shifts | Feeds the Emotional Head to track mood-dependent memory. |
| **Hebbian Firing** | Node IDs activated in the context window during $Q$ | Records co-occurrence events for "fire-together, wire-together" logic. |

## 3. Structural Logs (Captured by the Rust Resonator)

These logs track the **"Global Namespace"** and the health of the context graph itself.

*   **Graph Density:** Ratio of actual edges to possible edges.
*   **Significance Scores:** PageRank values of nodes after a SWS (Slow Wave Sleep) cycle.
*   **Cluster Modularity:** Strength of communities found via the Louvain Method.
*   **Memory Decay Rate:** Tracking nodes moving from Hot Storage to Cold Storage based on low energy.

## 4. Wisdom Logs (Captured by Mac Studio / Llama 4)

These logs capture the **"distilled" intelligence** and archetypal patterns.

*   **Archetypal Spawns:** The text and "Structural Shape" of new question nodes.
*   **Analogy Successful Matches:** Instances where $A:B :: C:D$ reasoning was confirmed.
*   **Relational Depletion Alarms:** Specific Aiden-inspired flags for "Burnout" or "Friction".
*   **Dharmic Alignment:** Degree to which agent choices align with pre-loaded "Teacher" nodes.

## 5. Educational Utility: The "PBL Insight" Log

To support your Project-Based Learning vision, the **Scribe nodes** will aggregate a specialized "Group Prompt" log.

*   **Log Trigger:** When Llama 4 identifies a persistent Archetypal Question that has gathered >50 related episodic nodes.
*   **Output:** A JSON object containing the question, the supporting "Analogies," and a suggested "Provocation" for human student groups.

## 6. Implementation Step

To make this real, the next step is to add a **Log Rotation script** to your Slurm `epilog`. This ensures that when a job on a Nano finishes, it doesn't just "poof" away—it pushes its Munge-signed JSON payload to your 8TB Thunderbolt drive for the Mac Studio to digest.

```mermaid
graph LR
    subgraph Compute ["Compute Nodes (Slurm)"]
        Nano[Nano (Episodic Job)]
    end

    subgraph Storage ["Central Storage"]
        Drive[("8TB Thunderbolt Drive")]
    end

    subgraph Analysis ["Mac Studio"]
        Ingest[Log Ingestion]
        Resonator[Rust Resonator]
    end

    Nano -->|Slurm Epilog<br/>(Munge-Signed JSON)| Drive
    Drive --> Ingest
    Ingest --> Resonator
```
